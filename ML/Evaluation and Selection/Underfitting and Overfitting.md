
Underfitting:
Definition: Model is too simple/constrained to learn the underlying pattern → poor performance on both training and test data. Statistically = **high bias, low variance**.
Example: Fitting a straight line y = ax + b to data generated by y = 3x² + 2x + 5.

How to Overcome It
Capacity:
- Use a more powerful model (linear → polynomial/kernel SVM/deeper tree/boosting/bigger net/LSTM)
- Raise capacity hyperparameters: max_depth, n_estimators, neurons, layers; unfreeze layers
Data & features:
- Add informative features; do feature engineering (polynomials, interactions, ratios, logs, time features, embeddings)
- Add/improve training data (representative, balanced, well-labeled) — but only helps if curves aren't already converged
- Fix labels, class imbalance (class weights, oversampling, macro-F1)
- Reduce excessive dimensionality reduction
Training:
- Train longer (more epochs/boosting rounds), fix early-stopping patience
- Tune optimizer: better lr/schedule, Adam/SGD+momentum, normalization, gradient clipping
Constraints:
- Reduce regularization — lower L1/L2/dropout, raise SVM C, loosen pruning
- Fix preprocessing (scaling, encoding, missing values)
- Add nonlinearities/interaction terms (a deep net of only linear layers ≡ one linear layer)


Overfitting in ML:

Definition: Model learns training data too well — including noise, outliers, and accidental patterns — so it excels on training data but fails on unseen data. The model memorizes instead of learning general rules. Statistically = high variance, low bias.
Example: A cat/dog classifier that memorizes background, lighting, and camera angle instead of ears, face shape, and body structure.
